public abstract DrmSessionManager getDrmSessionManager(PlaybackOptions options)

Get a DrmSessionManager. that is ready to communicate with the DoveRunner server DrmSessionManager can be managed directly by the customer.

With PlaybackOptions.forceStreaming a fresh license is always requested from the license server. Otherwise, if an offline license has been downloaded, the returned manager uses it so playback works without a network connection.

The same manager instance is returned while the resolved offline license stays the same, so re-preparing the same player (e.g. calling setMediaItem() again after onResume) reuses the DRM sessions that are already loaded instead of requesting a new license — important when the license token has a short validity. A recreated player is detected automatically and transparently gets a fresh internal manager; in that case a new license request is made, so issue a new token before re-preparing if the previous one may have expired.

Parameters

options

Per-call playback options, see PlaybackOptions. The SDK keeps no state for them, so the same SDK instance can hand out an offline DrmSessionManager and a streaming one without being released and recreated.
